{{/* Maps one authored path, as Studio writes it into front matter, to the place the v3 build serves it. Studio writes file paths for the v2 site (/courses//), but v3 courses are served under /courses/o//. The mapping is canonical_course_url.html, the one the v3 og:image already uses. It keeps the course slug, so a path into another course stays in that course, and it leaves anything that is not an OCW course path untouched: relative paths, other hosts (YouTube, archive.org), and paths already under /courses/o/. A value that is not a non-empty string is returned as is. */}} {{- $value := . -}} {{- if and (eq (printf "%T" $value) "string") (ne $value "") -}} {{- $value = partial "canonical_course_url.html" $value -}} {{- end -}} {{- return $value -}}
